# Fonts for matplotlib charts (SIL Open Font License).

This folder holds TTF faces registered by ``visualization.style``:

- **Cormorant Garamond** — figure / subplot titles (`VIZ_TITLE_FONT_FAMILY`)
- **Barlow** — axis titles, ticks, legend, annotations (`VIZ_BODY_FONT_FAMILY`)

Licenses: see `OFL-CormorantGaramond.txt` and `OFL-Barlow.txt`.
